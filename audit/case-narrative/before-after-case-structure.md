# Before / after case structure

| Before                                              | After                                                                    |
| --------------------------------------------------- | ------------------------------------------------------------------------ |
| Hero led with project value / visual record         | Hero leads with sourced market moment; verified role is separate         |
| Project Objective then generic Business Context     | Market Moment and Why It Mattered precede the narrower project objective |
| Archetype-generated shared challenge                | Case-specific sourced/owner-confirmed challenge                          |
| Venus Bridge role without visible negative boundary | “Did” and “Did not claim” displayed together                             |
| Universal “Strategy / Approach”                     | Evidence-sensitive approach label                                        |
| Image count as outcome headline                     | Useful deliverables first; image count secondary                         |
| Outputs / Outcomes regardless of evidence           | Verified Outputs and Verified Result separated                           |
| “What remained useful” only                         | Optional subsequent company context carries no-attribution disclaimer    |
| General scope note                                  | Evidence basis and claim boundary close every Tier 1 case                |
