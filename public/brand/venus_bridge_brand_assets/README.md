# Venus Bridge Brand Asset Pack

Source: owner-supplied 2048×2048 brand board.

## Brand hierarchy

**Primary customer-facing brand:** VENUS BRIDGE  
**Descriptor shown in the supplied logo:** GLOBAL PARTNERSHIPS

Important: this asset pack does **not** authorise changing the legal company name,
contracting entity, Privacy/Terms identity, or existing legal footer configuration.
`GLOBAL PARTNERSHIPS` is a brand descriptor in the supplied artwork, not a legal-entity claim.

## Recommended website usage

### Header / navigation
Use:
- `venus-bridge-horizontal-lockup-white.*` on dark header backgrounds, when there is enough width.
- `venus-bridge-monogram-white.*` for compact/mobile header states.
- Black variants only on light/ivory backgrounds.

Do **not** use the tall primary stacked lockup in the navigation bar.

### Homepage
The current homepage commercial architecture is frozen. Do not insert a large logo hero that competes
with the headline. Use the mark only as brand identity in the header / opening sequence if appropriate.

### About
Do not redesign the About page. The logo can appear only where an existing brand-mark component
already belongs; do not add a decorative logo section.

### Footer
Preferred:
- `horizontal-lockup-white` on the current dark footer.
Alternative:
- `primary-stack-white` only if the footer composition has sufficient vertical room.

### Opening / loading identity
If the site currently has an opening identity animation, use `monogram-white` or
`monogram-circle-white` as the visual mark, preserving reduced-motion behavior.

### Favicon / app icon
Use the monogram icon files from `/favicon`.

## Clear-space rule
Preserve at least approximately the height of the “V” stem around the primary/horizontal mark.
Never stretch, skew, rotate, add shadows, glows or gradients.

## Colour rule
Only use:
- black mark on ivory/light backgrounds
- white mark on black/dark backgrounds

Do not recolour the supplied logo gold unless the owner separately approves a gold master.

## Technical rule
Prefer WebP for rendered website imagery where supported, PNG where transparency fidelity is required,
and the ICO/PNG icon assets for metadata.

## Raster limitation
These assets were extracted faithfully from the supplied raster artwork.
They are suitable for the current website, but for large-format print or future identity work,
obtain the original vector master (SVG/PDF/AI) from the logo designer rather than auto-tracing this JPEG.
