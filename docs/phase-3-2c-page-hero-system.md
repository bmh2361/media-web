# Phase 3.2C Page Hero System

## Shared rules

- Preserve black, cream, bronze and pearl palette; established typography; logo and navigation.
- Reserve the largest typography for one clear page proposition.
- Use one primary visual idea per hero and preload only its essential first image.
- Every image must have a governed record, responsive dimensions, focal treatment and bilingual alt text.
- No hero depends on hover to communicate its meaning.
- Reduced motion receives an equivalent static composition.
- Mobile is designed independently; it is not a shrunk desktop layout.
- Avoid a repeated black block with a large left headline and small right paragraph.

## Home — cinematic editorial multi-scene

- Split text/media composition on desktop with four slow scenes.
- Scene labels: Industry, Technology, People, Production / 行业、技术、人与合作、创意制作.
- Manual controls expose current scene and support keyboard/touch.
- No fast carousel, autoplay announcement or paragraph per scene.
- Mobile uses a static robotics/technology scene with no cycling.

## Capabilities — interactive capability index

- Hero question: “What can we build around your UK objective?”
- Four numbered anchors are part of the hero composition.
- Focus/hover may change the preview for capabilities 02–04.
- Capability 01 remains typography-led; no image is used to imply institutional access.
- Mobile presents a natural four-row index and no preview carousel.

## Work — visual evidence mosaic

- Project imagery occupies the opening field before a concise headline and introduction.
- Four named public projects create category breadth.
- The visual mosaic is static and stable; no auto-motion.
- Mobile uses two deliberate stacked crops rather than reproducing the full desktop mosaic.

## About — editorial rationale

- A clear WHY VENUS BRIDGE proposition pairs with real working environments.
- Media is captioned as project environment/production, never as an invented team portrait.
- Typography and one asymmetric working-scene composition create humanity.

## Contact — minimal conversation-first

- No portfolio hero image.
- The headline, a short expectation-setting paragraph and form transition create the page grammar.
- The hero flows directly into the enquiry without a large empty black stage.

## Case study — adaptive evidence hero

- `cinematic`: wide event/automotive/brand-film environments.
- `portrait-editorial`: fashion, beauty and talent-led projects.
- `split`: mixed visual/context projects.
- `text-first-confidential`: future approved evidence with no imagery.
- The mode derives from governed project/media metadata, not arbitrary page overrides.

## Motion language

- Fade and crop changes connect context; no scroll hijacking or constant parallax.
- Active-state transitions use 400–700 ms easing.
- Hero auto-advance, where enabled on desktop, pauses on pointer/focus and stops under reduced motion.
- Interactive indexes use visible focus, actual buttons/anchors and `aria-current`/pressed semantics where appropriate.
