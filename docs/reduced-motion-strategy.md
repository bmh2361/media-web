# Reduced Motion Strategy

Reduced motion is a complete presentation mode, not a content-removal mode.

- opening identity is skipped;
- route transition duration resolves to 10ms;
- all parallax and pointer-following behaviour is disabled;
- sticky desktop media becomes static or changes without travel;
- ambient rails become static wrapping lists;
- media, captions, project disclosures and case credits remain available;
- mobile navigation, language switching and form progress remain functional;
- no content depends on hover or animation completion;
- CSS globally constrains animation and transition duration while component logic also selects static variants.
