# Phase 3.2D layout and grid system

## Width roles

| Role           | Maximum | Purpose                                  |
| -------------- | ------- | ---------------------------------------- |
| Viewport wide  | 1440px  | cinematic media and publication openings |
| Editorial main | 1320px  | primary 12-column composition            |
| Standard       | 1200px  | text/media chapters and forms            |
| Reading        | 760px   | long-form explanation                    |
| Narrow         | 620px   | short statements and focused prompts     |

Gutters are fluid: 20px at mobile, 28–40px through tablet and 48–60px on large desktop.

## Grid

- Desktop: 12 columns with 24–32px gutters.
- 1024/tablet landscape: six conceptual columns; two-part compositions must rebalance explicitly.
- 768: two or six columns only where the relationship remains strong.
- Mobile: one primary flow; supporting media may form a two-item row only when each remains legible.

## Composition patterns

- 7/5 hero: wide proposition and substantial landscape evidence.
- 4/8 outcome: selectable commercial language with one dominant visual.
- 5/7 editorial feature: metadata/copy beside authoritative evidence.
- 8/4 reverse feature: alternating publication rhythm.
- 12 cinematic: one image interrupts the page at full editorial width.
- 7 + 5 selected work: one dominant landscape and one secondary portrait/editorial project.

## Vertical rhythm

- Major chapters: 112–152px desktop, 72–104px tablet, 64–84px mobile.
- Related subsections: 56–88px desktop, 40–64px mobile.
- Media-to-caption: 14–20px.
- Heading-to-lead: 24–36px.
- Dead space that neither frames a focal point nor introduces the next chapter is removed.

## Responsive rule

Recomposition is preferred to proportional shrinkage. Hero, capability preview, selected work and media sequences each declare their own tablet/mobile hierarchy.
