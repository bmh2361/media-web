# Production Release Gates

Production must fail or remain blocked when:

- public pricing, package or predefined range language is present;
- the production domain is missing, local or a sample domain;
- contact delivery, allowed origins or webhook configuration is missing;
- legal review or public company details are not confirmed;
- demo brand marks or media guides are enabled;
- critical hero/service/industry media remains placeholder content;
- verified work uses restricted or placeholder media;
- concept work lacks explicit disclosure;
- portfolio mode has no eligible evidence;
- contact delivery has not been tested;
- critical media lacks meaningful alt text;
- video content lacks a poster;
- locale routes are incomplete.

Staging may use placeholder/demo media only when visibly disclosed and documented. Staging validation therefore reports asset warnings while still allowing review.

Environment confirmations must only be set after real human review; the validator does not fabricate approval.
