# Phase 3.2D adversarial design review

## Review posture

This review treats familiar component patterns, unexplained emptiness and decorative evidence as failures even when the implementation is technically correct.

## Pass 1 findings

- P1 — Homepage desktop: the active lead frame was visually contained and read as a screen inside a dark card, not authoritative evidence. Fixed by enforcing cover treatment.
- P1 — Capabilities production: a vertical sequence of five large frames extended the page without adding five distinct commercial ideas. Fixed by reducing it to four outputs on a 7/5 editorial rhythm.
- P1 — Work brand-film feature: a generic aerial frame did not immediately communicate the commercial story. Fixed with a stronger approved production frame.
- P2 — Header/buttons: pill controls and a gold-filled header CTA retained a SaaS/lifestyle signal. Fixed with small-radius, ruled controls and restrained accent use.

## Pass 2 findings

- P1 — Homepage desktop lead: the stage frame remained formally correct but visually flat and distant. Fixed by selecting the approved Changan cover image with greater activity and depth.
- P1 — Work supporting grid: the fifth card became an orphan and the weakest remaining automotive image. Fixed by removing it from the selected supporting composition.
- P1 — About: the same panel image appeared in two chapters, making the page feel asset-poor and assembled. Fixed by removing the repeated process image and strengthening the process statement.
- P2 — Capabilities mobile remains long. This is accepted because the four capability chapters and four project routes are required, but media count has been reduced and each sequence now has a clear focal hierarchy.

## Template / AI-pattern audit

- No gradient-led hero, floating dashboard card system, generic testimonial strip or excessive rounded-card vocabulary remains.
- Repeated “large heading plus tiny paragraph” contrast was reduced by raising body and metadata floors.
- The layout no longer uses a mosaic as the default proof grammar; only one controlled creator composition remains.
- Accent colour no longer occupies large surfaces, avoiding hospitality and generic luxury coding.

## Perception risks after fixes

- Photography-studio risk: low; imagery is consistently paired with objectives, roles, outputs and project context.
- Model-agency risk: low; creator imagery is limited to one capability chapter and people are not presented as a catalogue.
- Generic-consultancy risk: low-to-medium; the institutional chapter is intentionally text-led, but adjacent event, technology and production evidence prevents the site becoming purely diagrammatic.
- Over-luxury risk: low; gold is limited to small markers and the typeface remains a neutral international sans.

## Remaining severity

- P0: none.
- P1 after corrective edits: none identified; pass 3 must verify the result at all five widths.
- P2: long Capabilities mobile flow; fourth homepage project rail item remains horizontally discoverable; case galleries remain evidence-dense by design.
