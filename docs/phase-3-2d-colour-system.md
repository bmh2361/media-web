# Phase 3.2D colour system

## Palette

| Token role | Value | Purpose |
| --- | --- | --- |
| Ink | `#0b0d0e` | primary authority surface |
| Night | `#141719` | tonal dark separation |
| Graphite | `#242729` | media fallback and quiet dark layer |
| Ivory | `#f3f0e9` | primary editorial ground |
| Porcelain | `#f8f6f1` | high-clarity reading ground |
| Stone | `#e8e4dc` | restrained chapter separation |
| Slate | `#5d6264` | secondary text on light |
| Champagne | `#c8a56a` | small, high-impact accent |
| Light-surface accent | `#805f35` | small labels and indices on neutral canvas; AA at the text sizes used |

## Ratio

The intended page balance is approximately 70% ivory/neutral, 25% dark and no more than 5% accent. This is compositional guidance rather than an exact calculation.

## Rules

- Large ochre, brown or gold fields are removed.
- Champagne appears in the logo, eyebrows, thin rules, indices and selected interactive states.
- Near-black sections signal authority, technology or a major transition; they do not alternate mechanically with every light section.
- Only Ivory, Porcelain and Stone form the light family.
- Depth comes from adjacent tonal planes, media scale and grid offset—not shadow stacks.
- Final CTAs use Ink or Ivory so they resolve the established page palette.
- Text and interaction states retain WCAG-compatible contrast.
