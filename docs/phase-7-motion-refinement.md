# Phase 7 Motion Refinement

## Dominant ideas

- Homepage: cinematic production sequence.
- Work: project discovery and media replacement.
- Commercial Production: reel, film frame and format transformation.
- Talent: private contact-sheet assembly.
- Events: multi-camera and run-of-show choreography.
- Agency: operational handoff.
- Research: technical information resolving into clear communication.

## Refinements

- Retained the Phase 6 token system.
- Added route announcements without slowing transitions.
- Kept opening identity below one second and session-only.
- Preserved bounded hero parallax and disabled it on touch/reduced motion.
- Kept ambient movement limited to the sector rail.
- Avoided adding new global effect systems.
- Kept pointer labels off touch and native text/form controls.
- Reduced chapter scroll distance during Phase 6 visual QA and retained that tighter pacing.

## Risks reviewed

- Repeated curtain reveals: acceptable for media identity, but not added to body text.
- Sticky chapters: desktop only; mobile uses direct vertical content.
- Animated rail: pauses on interaction and becomes static under reduced motion.
- Route slate: decorative, short and non-blocking.
- GPU use: no WebGL, particle fields or large animated blur.
