# Homepage desktop composition audit

## Composition problems identified

The desktop homepage was strong but several text-led chapters placed a narrow headline in the upper-left while leaving the upper-right without a narrative role. The clearest case was **When Companies Bring Us In**, where the English headline occupied four lines at 1280–1600px before a five-column evidence system.

## Repeated layout patterns

The nine homepage chapters mapped as follows:

| Section | Composition type | Audit outcome |
| --- | --- | --- |
| Hero | A — text + dominant media | Preserved |
| Real Projects | C — full-width visual evidence | Preserved |
| When Companies Bring Us In | B — positioning + contextual explanation | Refined |
| What We Help Make Happen | D/E — indexed dark chapter | Refined |
| Local Capability | F — asymmetric two-audience proof | Preserved |
| Capability Around the Goal | D — indexed horizontal system | Preserved |
| Exhibition to Pipeline | G/D — editorial statement + process index | Refined |
| Why Venus Bridge | F — asymmetric proof composition | Preserved |
| Closing CTA | H — closing conversion section | Preserved |

The repeated formula was eyebrow + narrow upper-left headline + system below. It appeared most noticeably across the journeys, model and work chapters.

## Sections modified

- **When Companies Bring Us In:** widened the headline, added a concise contextual explanation on the right, aligned the five situations typographically, and integrated the CTA with the lower rule.
- **What We Help Make Happen:** widened the statement while retaining the dark indexed system and the sitewide editorial spine.
- **Exhibition to Pipeline:** widened the statement and retained its relationship to the process index on the sitewide editorial spine.

## Headline-width changes

The journeys headline changes from a narrow 15-character measure to a seven-column, 18-character desktop measure. The model and work statements now use the shared sitewide desktop measure roles while retaining their existing sizes and all smaller-breakpoint behavior.

## Whitespace strategy

Whitespace remains generous. The journeys upper-right explains why the five situations matter; the model and work chapters use the established editorial spine and let the indexed systems below carry the horizontal field.

## Section rhythm improvements

The desktop sequence moves from visual proof to a balanced commercial split, then to an indexed dark chapter. Later, the existing split capability section is followed by a process chapter and a left-led proof chapter. Composition varies through media, tone and information structure without breaking the shared headline spine.

## Mobile protection

All composition changes begin at the `xl` breakpoint (1200px). The new contextual layer is hidden below that breakpoint, preserving mobile length and complexity as well as navigation, interaction, media, motion, and case-study architecture.

## Remaining optional refinements

No further structural changes are recommended in this pass. A future content phase could consider whether the contextual sentence should be incorporated into the approved copy system, but it is not required for release.
