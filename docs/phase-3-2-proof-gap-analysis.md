## Direct-proof status

- Level A institutional/expert case: **MISSING**.
- Level A end-to-end creator activation: **MISSING**.
- Level A broader event orchestration beyond content capture: **MISSING**.
- Level A creative production: **STRONG**.

## Priority order for owner curation

1. Institution/expert + company with permissioned relationship evidence.
2. Launch/activation + commissioned creator or talent + production.
3. Exhibition/industry event with verified broader local execution and stakeholder outputs.
4. UK production with approved China-facing usage and measurable result where available.

These cases should strengthen the frozen four capabilities and four project types. They do not justify new programmes, routes or homepage sections.
