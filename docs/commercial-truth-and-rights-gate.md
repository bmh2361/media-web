# Commercial Truth and Rights Gate

## Repository evidence state

The canonical portfolio registry publishes only records marked completed, verified, client-approved, legal-approved and public. Its media records require website-use, media-rights and copyright approval. Capability and portfolio media manifests also carry bilingual alt text and explicit public approval fields. Automated release validation checks these contracts.

This provides a strong internal governance mechanism but does not independently prove the underlying approvals. The global production confirmation variables remain unset in the audited environment.
