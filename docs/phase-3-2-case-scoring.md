# Phase 3.2A Case Scoring

Date: 12 August 2026  
Use: internal comparison after truth and rights gates. A total never authorises publication by itself.

## Rubric

Score each dimension from 1–5.

| Dimension | 1 | 3 | 5 |
| --- | --- | --- | --- |
| Strategic Relevance | Peripheral to current positioning | Proves one useful part | Directly embodies UK partnerships, credibility and execution |
| Credibility | Context cannot be publicly established | Credible but limited recognition/context | Highly credible, recognisable and precisely evidenced environment |
| Role Strength | Incidental or unclear | Meaningful narrow role | Substantial multi-component Venus Bridge role |
| Evidence Quality | Anecdotal/incomplete | Adequate records with some gaps | Strong documentary record supporting every public claim |
| Visual Quality | Unusable or rights-limited | Serviceable supporting visuals | Distinctive premium visuals with clear evidential value |
| Differentiation | Commodity proof | Some specialist value | Demonstrates a defensible combination competitors may struggle to replicate |
| Buyer Relevance | Target buyer cannot see a use case | Relevant to one segment | Immediate, high-value use case for target CEOs/CMOs |
| Conversion Potential | No natural next project | Supports a conversation | Makes a similar substantive project easy to imagine |
| Rights Confidence | Unknown/restricted | Partial approval or narrow use | Exact wording, identities and media fully approved |
| Cross-Capability Value | Isolated execution | Proves one capability strongly | Credibly proves several frozen capabilities in one project |

`TOTAL SCORE = sum of all 10 dimensions`  
Maximum: 50.

## Interpretation guide

| Total | Initial interpretation | Human review question |
| ---: | --- | --- |
| 44–50 | Hero candidate | Does it materially improve perception and deserve one of only 3–4 Early Proof positions? |
| 38–43 | Core candidate | Which capability or project type does it prove most clearly? |
| 30–37 | Supporting candidate | Does it add evidence not already supplied by a stronger case? |
| 20–29 | Visual or archive candidate | Is the visual value commercially useful, or is publication just adding volume? |
| 10–19 | Archive | Is there any truthful, differentiated buyer value worth recovering? |

These bands are guidance only. A score cannot overcome an evidence, relationship or rights failure.

## Overrides

- Rights Confidence of 1–2 blocks public placement.
- Level C and D block public case placement regardless of score.
- An unclear Venus Bridge role blocks Hero/Core classification.
- Institution, creator, talent or event wording that exceeds the recorded relationship blocks publication.
- A high-recognition logo cannot compensate for a weak role.
- Redundant evidence may receive a lower placement even with a strong score.
