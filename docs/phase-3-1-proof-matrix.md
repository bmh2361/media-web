# Phase 3.1 Proof Matrix

Date: 12 August 2026  
Purpose: govern public capability wording and expose evidence gaps without manufacturing authority.

Evidence levels:

- **Level A — Direct Verified Proof:** a rights-approved public project directly proves the narrow claim.
- **Level B — Adjacent Operating Proof:** public work proves important delivery components but not the complete claim.
- **Level C — Current Operating Capability Without Public Case:** may be described conservatively if the owner confirms it is currently deliverable; no named access or outcome may be implied.
- **Level D — Aspirational:** not sufficiently evidenced as a current capability and excluded from public claims.

## Public wording rules derived from the matrix

1. Level A wording uses the narrow role recorded in the approved portfolio.
2. Level B wording names the proven component and never silently expands it into full programme ownership.
3. Level C wording uses “may”, “depending on the objective/scope” and unnamed engagement formats; it requires owner confirmation of current deliverability.
4. Level D wording does not appear as a current public claim.
5. Brand, institution, event, expert and talent names require identity, scope and publication permission.
6. Engagement, participation, commissioned work, sponsorship, official partnership and endorsement are never treated as synonyms.
