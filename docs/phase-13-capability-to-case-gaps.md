## Required intake before Work publication

The user must provide the project name, client or subject, date, location, Venus Bridge Media's actual responsibilities, final deliverables, and publication or delivery evidence. Client naming, outcomes, metrics and structured CreativeWork data remain blocked until those facts pass the existing public case gate.
