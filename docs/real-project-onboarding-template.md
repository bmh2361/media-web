## Validation rules

- Verified projects require a real date, approved media, approved disclosure and eligible evidence.
- Anonymised projects cannot expose identifying client metadata.
- Confidential projects expose only explicitly approved fields.
- Concept projects use a separate workflow and never count as primary Selected Work.
