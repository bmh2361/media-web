## Replacement procedure

1. Add source and optional mobile source in `content/media.ts`.
2. Set route, section, purpose, aspect ratio and focal point.
3. Add bilingual alt text and optional public caption/credit.
4. Associate project media with `projectId`.
5. For video, add poster; for speech, add captions or transcript.
6. Record rights and client approval.
7. Set `approvalStatus: "approved"` only after human approval.
8. Run media, content, staging and production validation.
