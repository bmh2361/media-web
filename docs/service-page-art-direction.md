# Service Page Art Direction

## Commercial Production

Film and photography production desk. Uses a poster-led reel slot, storyboard/contact-sheet media, delivery ratios, timecode and production disciplines. Audio never autoplays.

## Talent, Casting and Styling

Private casting workspace. Uses anonymous contact sheets, selection criteria, rights dimensions and a private shortlist process. It does not expose a public talent database.

## Events and Exhibitions

Live operations system. Uses event architecture, run-of-show, multi-camera coverage and an authored responsibility matrix. Flashing and microphone-reactive effects are excluded.

## Agency Support

Discreet operational interface. Uses responsibility ownership, white-label boundaries, workflow media, approval structure and asset handoff.

## Research and Innovation

Technical communication archive. Uses a resource map, research-to-public sequence, reviewed outputs and explicit approval language. No institutional relationship is implied.

## Shared constraints

Only breadcrumbs, media contracts, accessibility foundations and final project actions are shared. Page narrative, visual rhythm and primary interaction model remain service-specific.
