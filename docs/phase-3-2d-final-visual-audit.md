## System result

The site now uses one consistent premium editorial system: ink-led high-contrast surfaces, neutral porcelain canvases, champagne only as a controlled accent, wider twelve-column compositions, ruled information planes, fewer simultaneous images, stronger type scale and larger evidence media. The commercial strategy, four-capability architecture, four project types, navigation, CTA destinations, evidence governance and truth gates remain unchanged.

The previous gold-brown block treatment is no longer used as a large section background. Dark conversion planes carry final CTAs, while the champagne colour is reserved for small rules, indices and identity details. Cards, pills, floating shadows and application-like selected states have been removed from primary editorial presentation.

## Three-pass review record

### Pass 1

The rebuilt grid, typography, colour system and media hierarchy were applied across the route matrix. Inspection identified three material issues: the homepage lead image was too contained, the production capability still felt exhaustive, and a Work image read as weak aerial documentation rather than useful commercial evidence.

### Pass 2

The homepage media was made immersive, production outputs were reduced to four and composed on a 7/5 editorial grid, and the weak Work frame was replaced. Inspection then found a formally correct but visually flat homepage lead, an orphaned fifth supporting Work card and repeated About media.

### Pass 3

The homepage lead was replaced with the stronger Changan floor view, the supporting Work grid was reduced to four projects, and the repeated About process image was removed in favour of a concise type-led statement. The full route matrix was recaptured and manually inspected. No P0 or P1 visual defect remained.

## Required 1440 comparisons

### Home

The baseline used a narrow text tower, a contained vertical hero, a modular capability collage and a large brown conversion band. The final page uses a broad 7/5 hero, a commercially stronger event-floor frame, a one-dominant early proof rail, a ruled capability index, more deliberate selected-work scale and a dark conversion plane.

### Capabilities

The baseline read as a selected-state interface followed by six-image mosaics. The final version treats the capability selector as an editorial field, enlarges industry evidence, reduces creator evidence to three deliberate frames and reduces production evidence to four outputs with a clear dominant image.

### Work

The baseline gave four hero images similar weight, used a weak aerial production frame and ended with an orphaned fifth supporting card. The final version creates one dominant hero image with two supporting frames, uses a stronger production image and resolves supporting work as an even four-project grid.

### About

The baseline hero used an ambiguous people image that could be interpreted as a team portrait, repeated media later in the page and ended in a brown CTA band. The final version uses a real industry-context robot image, retains one useful panel image, makes the process section type-led and ends on the dark conversion plane.
