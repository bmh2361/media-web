## Register rules

1. “Current registry approvals are true” describes the existing `PortfolioProject` record; it is not perpetual permission for materially different wording or placement.
2. A mixed Level A/B row must state which narrow claim is Level A.
3. No score or strength automatically promotes a case.
4. Future owner records are added only after intake; missing fields remain blank or `UNKNOWN`.
5. Archived and restricted cases remain in the internal register but not the public Work index.
