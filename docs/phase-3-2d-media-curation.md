# Phase 3.2D media curation

## Selection order

1. commercial meaning;
2. evidence strength;
3. visual quality;
4. relevance to the surrounding claim;
5. strategic breadth.

Every selected asset must answer “why this image?” with more than appearance.

## Ratio family

- feature cinematic: 21:9 or wide 16:9;
- feature landscape: 16:9;
- editorial landscape: 4:3;
- editorial portrait: 3:4;
- campaign portrait: 2:3;
- detail: 1:1.

Raw source dimensions never select a layout role.

## Repetition rule

No asset should appear three or more times across primary page surfaces unless it is the deliberate lead identity of one project. Repeated project identities should use a different approved frame where the registry permits.

## Crop protection

Desktop, tablet and mobile crops are checked for faces, eyes, hair, vehicles, products, logos, stage screens and relevant environmental context. Cover treatment uses the approved unpadded source when art-directed derivatives contain baked-in matte areas.

## Mobile

Fewer images appear at larger scale. Dense six- or eight-frame collages collapse into one lead and at most two supports.
