The CTA vocabulary is already constrained to Discuss a UK Collaboration, View Selected Work, Explore Capabilities and contextual project links. The Contact form already uses the recommended short field set and does not request budget.

## Current buying logic

The Phase 3 site explains who Venus Bridge is and what four capabilities it coordinates. A buyer can infer suitable projects, but must assemble the buying logic themselves. The missing bridge is:

`client objective → project format → possible UK activity → outputs → relevant capability → verified proof`

This can be introduced inside the existing Capabilities programme section. No homepage section needs to be added.

## Evidence asymmetry

The public portfolio directly proves event/exhibition content, automotive photography, UK-located brand-content production and fashion/beauty image production. It provides adjacent operating proof for talent/styling coordination and multi-component brand activation. It does not directly prove institutional partnerships, academic programmes, endorsement, complete event orchestration or measurable brand outcomes.

Institutional & Expert Collaboration should remain only as a precise operating capability: legitimate engagement formats may be coordinated, named access is not promised, and engagement is not endorsement. It should not receive artificial imagery, logos, testimonials or inferred proof.

## P0 problems

None identified. The current public site does not reintroduce market-entry positioning, publish a Level D institutional claim, fabricate metrics or expose a broken canonical conversion route.

## P1 problems to implement

### P1.1 — Programme examples are not yet buyable

The current three examples provide names and a sequence of components only. They do not answer the objective, possible UK activity, outputs, relevant capability or relevant proof. Replace this existing block with four concise, non-fixed project types:

1. International Credibility Project
2. UK Industry Presence Project
3. International Brand Activation
4. UK Brand Content Production

The fourth is necessary to distinguish the strongest proven entry product from broader activation. The language must use “designed around”, “may include” and “relevant proof”, never fixed inclusions or prices.

### P1.2 — Capabilities page ends with an empty proof promise

The current Selected Work section contains a heading and button but no project evidence. Remove that empty, duplicated section and connect each project type directly to relevant verified proof. This makes proof contextual while reducing the page from nine to eight sections.

### P1.3 — Homepage capability rows lack engagement examples

Add three short representative formats per capability within the existing rows. Reduce surrounding capability introduction, outcome descriptions and repeated explanatory copy so total homepage words decrease rather than increase.

### P1.4 — Work ordering is not strategically intentional

The current execution order begins CATL, BYD, Changan. Use a fixed strategic order: Changan, BYD, CATL, Leapmotor, London Automotive Brand Story Film, followed by automotive road/lifestyle and then fashion/beauty capability evidence. This places major European commercial environments before purely visual production evidence.

### P1.5 — Work cards do not make proof-to-capability mapping explicit

Add a compact “Proves” line using shortened display labels for the four canonical capability names. Remove the duplicated role line from the visual index because the exact role remains on each case page; this keeps Work index density approximately neutral.

### P1.6 — Why Venus Bridge does not fully answer why not hire suppliers separately

Refine the existing section—not its size—to state the supported commercial advantage: one bilingual coordination layer assembles fragmented UK people, environments and production around a single outcome, then turns the activity into reusable assets.

### P1.7 — Proof governance needs an operational record

Create a Level A–D proof matrix and owner evidence intake SOP. Level D claims remain excluded from public copy. Level C claims remain precise and unnamed.

## High-confidence P2 improvements

- Tighten early-proof metadata to brand/project, UK/European context and exact role without descriptive adjectives.
- Refine outcome descriptions to state why the outcome matters commercially.
- Add project-type context to Contact’s optional support choices while keeping the field count unchanged.
- Audit canonical metadata and redirects against the Phase 3.1 project vocabulary.
- Add automated content-density, CTA vocabulary, project ordering and evidence-level contracts.

## Opportunities not being implemented

- No new homepage section, top-level route or capability.
- No pricing, public packages, diagnostic, comparison table or service tree.
- No institutional name, logo, testimonial, expert identity or stock “academic authority” imagery.
- No metrics, brand outcomes or full event/campaign ownership inferred from production records.
- No budget field or longer qualification form.

## Implementation success criteria

- Homepage remains at exactly 8 sections and decreases from 508 rendered English words.
- Capabilities decreases from 9 to 8 sections and does not materially exceed 486 words; any increase must be offset by clearer buying logic and reduced duplication.
- Work remains at 3 sections and stays close to 221 words.
- Exactly four project types appear in the existing programme section.
- Every project type presents Objective, Possible UK Activity, Outputs, Relevant Capabilities and Relevant Proof.
- Changan, BYD and CATL appear first wherever strategic execution proof is prioritised.
- Institutional engagement is clearly distinguished from endorsement and has no invented proof.
- The canonical CTA vocabulary remains small.
- EN/ZH runtime validation passes at 1440, 768 and 390 with no horizontal overflow or console errors.
